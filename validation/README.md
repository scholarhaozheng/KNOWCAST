# Numerical examples and module index

The examples cover recurrent gates, OD allocation, gravity balancing, path assignment, service-frequency conversion, losses, metrics and temporal alignment. Each example supplies its inputs and expected values.

| Resource | Contents |
| --- | --- |
| [Module index](MODULES.md) | Pseudocode modules and their roles |
| [Declaration index](modules.json) | Classes and procedures in each module |
| [Python scripts](scripts/README.md) | Numerical examples and a declaration check |

The scripts use the Python standard library and print their results as JSON. See the [algorithm guide](../PSEUDOCODE_GUIDE.md) for the complete forecasting procedure and the [paper](../docs/assets/knowcast-paper.pdf) for the reported experiments.
